# TradingAgents Backtest Dashboard

Single-page dashboard visualising 12 tickers × 25+ cohorts of strategy
backtests against the framework's signals. Generated entirely from the
local memory log — no Anthropic API calls.

## Features

- **Ticker / frequency selectors** (one of each at a time)
- **Dual-axis chart**: market price (left) + Strategy NAV vs Naive
  Buy&Hold NAV (right)
- **Position tier band** as background — purple shades show how much
  capital the strategy was allocating each period (0 / 50% / 70% /
  100%); red tint when drawdown brake was active. Percent labels
  annotate each change point.
- **Per-point markers** colored by rating (green Buy, lime Overweight,
  gray Hold), red ✕ on stop-loss months, larger marker for 2-month
  Buy confluence.
- **Hover tooltip** — date, prices, NAV, rating, target/actual position,
  raw vs realised P&L, and strategy rule notes.
- **Click a point** — modal pops up with the full LLM rationale for
  that decision (Final Decision, Trader Plan, Research Manager output,
  Market / Sentiment / News / Fundamentals analyst reports).
- **Dark/light theme toggle** in the header.

## Quick start

```powershell
# 1. Generate the data files (whenever memory log has new entries)
python scripts\build_dashboard.py

# 2. Serve the page (avoids file:// CORS)
python web\serve.py
# Opens http://127.0.0.1:8765 automatically
```

Or open `web/index.html` directly if your browser allows local
fetches; otherwise the data.json fetch will fail.

## What's in the data

```
web/data.json        all (ticker, cadence) trade-by-trade metrics
web/reports/<T>.json full LLM reports keyed by date — loaded only
                      when you click a point
```

`data.json` is ~270 KB total (lightweight, in-memory friendly).
Per-ticker reports range 200 KB – 2 MB depending on number of cohorts.

## Refresh after new signals

Whenever you run `propagate()` for new dates (e.g. weekly cron):

```powershell
python scripts\build_dashboard.py
```

…re-reads memory log, rebuilds JSON. Reload the dashboard tab.

## Strategy logic in the dashboard

- **Crypto tickers** use Strategy V1: 2-month Buy confluence → 100%,
  single Buy / Overweight → 50%, Hold → 0%; -15% intraperiod stop
  loss; -25% leg drawdown brake (1-period halt + peak reset).
- **Equity tickers** use Strategy V2: Buy 1.0 / OW 0.7 / Hold 0;
  no stop loss; -30% leg drawdown brake.
- 0.1% per-side fee on every realised P&L.

Same rules as `scripts/strategy_v1.py` and `scripts/strategy_v2.py`.
